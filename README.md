# No Color Land Part.2
Immersive Media Programming - VR Project
Team.3

1. Title: No Color Land Part.2
2. Genre: Horror
3. Concept: Room escaping + No Color Land (Our AR Project)
4. Story: The boy who are living in "No Color Land" entered mystery cave. He saw some clue and find key that can make to escape him from cave.
5. Level 1: Players should find some clue and key that is needed to escape and save No Color Land.
6. Level 2: Players should fight with monster and escape cave.
7. Monster: In Level 1, There is no explicit monster. There is only scary sound and ambience. In level 2, Monster should chase the player for protect the something that was taken by the boy.
8. Clue: what is the no color land? How to fight with monster? where is the main clues and key?
9. Key & Main Clue: The key and main clue for Level 2.
10. Oil lamp: Main light and weapon. Player can choose of color its light. And, player can get some color ball there. The color ball can be a weapon like flame, water….
11. Reference: Among the sleep, some escape game
